# Installation Guide

## Prerequisites

- Python 3.13 or 3.14
- Windows 10 or later
- pip

## Setup

Use the project virtual environment already in the workspace:

```powershell
cd "d:\Forget Lab"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Run the application

```powershell
cd "d:\Forget Lab"
.\.venv\Scripts\python.exe app.py
```

Then open http://127.0.0.1:5000
