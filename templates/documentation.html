REFERENCE / METHODS

Documentation

ForgetLab workflow and metric definitions.

Data and training

The default dataset is the UCI Adult Census Income data. Uploaded CSV files become the active dataset for the current application process. The target column is selected in Dataset Explorer.

Models are trained with a reproducible 80/20 split. Accuracy, precision, recall, F1, confusion matrix, ROC, precision–recall, AUC, and feature importance are computed from the held-out portion.

Unlearning methods

Exact retraining removes the selected rows and fits a new model as a reference baseline. Approximate SGD is experimental and must not be interpreted as a formal privacy guarantee.

Interpretation

Dashboard values reflect completed work in the current process. Empty charts indicate that a required model run has not yet been performed. The forgetting and retention counts refer to the current active dataset selection.

API surface

Dataset routes: /api/dataset, /api/dataset/preview, and /api/dataset/upload. Model and experiment routes: /api/train, /api/unlearn, /api/dashboard, and /api/history. Reports are available from /api/report/export/json and /api/report/export/csv.
